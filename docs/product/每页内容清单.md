## 1. `/` 落地页

**主标题**：`让每一项能力` / `都有证据可循`（"证据"二字高亮）
**顶部徽标**：`新` · `面向嵌入式校招 / 实习的证据化求职准备`
**副文案**：`从目标岗位出发，用真实项目验证你的能力、找到差距、生成专版简历。每一条结论都标明依据，告诉你哪些已被证明，哪些还需要补齐。`

**分区**
| 分区 | 内容 |
|---|---|
| 站头导航 | `四个阶段` `证据状态` `我们的承诺` |
| Hero 承诺区 | `我们对每一位求职者的承诺` → `结论可追溯` `排序可解释` `任务 < 90 分钟` `简历逐条确认` |
| 闭环流程 | `四个阶段，一条完整的准备闭环` → `建目标岗位` `项目验证` `差距计划` `专版简历` |
| 证据状态 | `每项能力，只会处于四种状态之一` → `已验证` `用户声明` `证据不足` `当前缺失` |
| 我们的承诺 | `现在开始，为下一份 offer 积累证据` → 四条承诺（见下） |
| 页脚 | `证途 · 证据化求职准备` / `面向嵌入式校招与实习` |

**四条承诺原文**
- `结论可追溯` — `每一条判断都能回到具体的证据来源。`
- `排序可解释` — `任务优先级附带理由，而不是黑盒打分。`
- `任务 < 90 分钟` — `单项补齐任务控制在一次专注时长内。`
- `简历建议逐条确认` — `不会在你不知情时改写任何一句话。`

**动作**：`登录`→/login · `注册`→/register · `开始准备`→/register · `已有账号，登录`→/login

**主张句**：`我们不替你夸大，也不替你谦虚。状态只取决于证据本身，你随时可以补充材料改变它。` · 图片角标 `一步一证，向上生长`

**空态/错误态**：无

## 7. `/resume/import` 导入简历

**主标题**：`导入简历`（index `01 · i`，eyebrow `Import`）
**副文案**：`粘进来，拆成一条条，再逐条核对。这一步不改变任何能力的状态 —— 只是把底料备齐。`

**分区**：返回 `我的简历` / **显著说明（不可折叠）** / `粘贴简历文本` / `逐条核对`（分组：`技能` `项目` `教育经历` `其他`）

**动作**：`填入示例简历` · `解析这份简历` / `重新解析` · `保存` · `取消` · `确认` / `已确认` · 编辑/删除 · `覆盖并重新解析` · `保留原来的` · `确认并保存`→/resume

**关键文案**
- 显著说明：`解析只是提取，不是验证。这里做的是把你写过的内容拆成条目，方便后面逐条核对。任何一条进来时都是「用户声明」，只有经过项目追问或提交材料之后，才可能变成「已验证」。`
- 输入限制：`目前只支持粘贴文本（不支持上传 PDF / Word）`
- 错误：`粘贴的内容太短，至少需要 20 个字符。`
- 覆盖弹窗：`已经有解析结果了，重新解析会覆盖它` / `当前 {N} 条，其中 {M} 条已确认。覆盖后已确认的状态不会保留。`
- 计数：`共 {N} 条 · 已确认 {M} 条 · 待确认 {K} 条`
- 底部：`还有 {N} 条未确认，保存后它们仍会以「用户声明」保留` / `全部条目已确认`

## 8. `/resume/tailor` 岗位专版简历

**主标题**：`岗位专版简历`（index `01 · ii`，eyebrow `Tailored`）
**副文案**：`针对「{目标岗位}」把简历调准。每条建议都逐条过一遍 —— 接受、改写成你自己的话，或者拒绝。强化表述必须站得住，否则面试第一轮就会露底。`

**分区**：返回 `我的简历` / `修改建议`（`共 {N} 条 · 待处理 {M} 条`）/ `简历预览` / 预览内 `全部版本`

**动作**：每条 `接受` `编辑` `拒绝`；`保存修改` `取消`；`保存为岗位专版`；冲突弹窗 `新建版本` `覆盖 v{n}` `取消`；`回到我的简历`

**状态与分支**
- 空态：`当前证据不足以提出任何修改建议` / `建议只能建立在已验证的事实上。现在还没有能撑住强化表述的证据，硬改会让简历在面试里被问穿。` / 动作 `先去补齐项目验证`
- 显著说明：`只强化有来源的事实。没有证据支撑的表述不会出现在建议里；即便出现了，没有来源的那一条也无法被接受。`
- 无来源门禁：`这条没有可追溯的来源，无法处理。请先补上项目验证或已确认事实，再回来处理它。`（`拒绝` 不受门禁）
- 状态标签：`待处理` `已接受` `已编辑` `已拒绝`；编辑后附 `已按你的文本`
- 预览：`绑定岗位 · {岗位} · {公司}` / `岗位强化表述 · 已纳入 {N} 条` / `还没有接受任何建议。接受后，强化后的表述会出现在这里。`
- 保存前：`还有 {N} 条未处理，它们不会进入简历。`
- 冲突弹窗：`「{岗位}」已经有一份专版简历了` / `当前最新是 v{n}。请选择新建一个版本，还是覆盖它 —— 不会替你决定。`
- 成功：`已保存 v{n} · {时间} · 绑定「{title}」· 纳入 {N} 条`
