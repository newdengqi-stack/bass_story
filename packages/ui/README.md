**当前为空。** 这是有意的，不是遗漏。

## 为什么现在的共享组件不在这里

`apps/web/components/shared/` 下的六个组件（证据状态标签、来源浮层、步骤指示器、任务卡、空态块、逐条确认条）**看起来像**设计系统，但目前不是：

- 它们直接消费 `app/globals.css` 里 `.ws` 作用域的 `--ws-*` 变量（`--ws-ink`、`--ws-sand`、`--ws-panel`…）
- 这套变量绑定在「内容直接落在照片上、靠文字投影保证可读」这一产品级视觉决策上，不是通用主题
- 抽出去就必须同时抽走 token 层，等于把整套视觉语言一起搬出来

在只有 `apps/web` 一个消费方的今天，抽它只会得到「一个必须回头看 app 的 css 才能用」的假组件库。

## 什么时候才该抽

- 出现第二个渲染同一套界面的应用（例如管理后台 `apps/admin`），或
- `--ws-*` 被抽象成与产品解耦的主题层，可以被不同产品复用

届时连同 token 定义一起抽，并同时提供默认主题。
